# Example Images — Imaris XTension Suite: Cochlear Implant Analysis

Example Imaris datasets for the Imaris XTension suite described in:

> Trang EP, Cho E, Wise A, Segal-Wasserman G, Fallon JB. *Light-sheet fluorescence microscopy and spatially resolved three-dimensional analysis of the chronically implanted and stimulated cochlea.* Manuscript in preparation.

Scripts and user guides: https://github.com/EllieCho/Imaris-XTension-Cochlear-Analysis

**Download:** https://doi.org/10.26188/31894942

Images were acquired using light-sheet fluorescence microscopy and downsampled for demonstration purposes. Original voxel size: 1.62 × 1.62 × 6.0 μm. Downsampled voxel size: 8.96 × 8.96 × 33.1 μm.

---

## Example Image — Unprocessed.ims

A starting-point dataset containing fluorescence channels and manually created 3D objects, intended for users to run the full XTension pipeline from scratch.

### Channels

| Channel | Content |
|---|---|
| Ch 1 | SGNs (Masked HuC/HuD) — auditory neurons masked to Rosenthal's canal |
| Ch 2 | Masked α-SMA — masked to scala tympani |

### 3D Objects

| Object | Type | Description |
|---|---|---|
| Rosenthal's canal | Surface | Anatomical region of interest housing the spiral ganglion neurons (auditory neurons). Manually segmented using the slice view within Imaris. |
| ST | Surface | Scala tympani — the anatomical region of interest where the electrode array is inserted. Manually segmented using the slice view within Imaris. |
| Electrode pos | Spots | Spots placed manually at the approximate centre of each electrode contact, identified from the shadow produced by the platinum electrodes in the fluorescence images. |

---

## Example Image — Processed.ims

Builds on the unprocessed dataset with additional channels and 3D objects generated by running the full XTension pipeline. All channels and objects from the unprocessed image are also present.

### Additional Channels

| Channel | Content | Generated by |
|---|---|---|
| Ch 3 | Spot Cylinders (per csv, Imaris ID+1) — cylindrical reconstruction of each electrode contact | `SpotsToCylinders.m` with per-electrode dimensions from `SpotsToCylinder_Electrode Array_VariousDiameter.csv` |
| Ch 4 | Voronoi tessellation channel | `SpotsVoronoiCreate.m` |
| Ch 5 | Ch 4 masked using enlarged electrode spots | Imaris Mask Channel |
| Ch 6 | Ch 5 masked using Rosenthal's canal surface | Imaris Mask Channel |
| Ch 7 | Ch 4 masked using Rosenthal's canal surface | Imaris Mask Channel |

### Additional 3D Objects

| Object | Type | Description | Generated by |
|---|---|---|---|
| Electrode pos_Resized_D2000.0um | Spots | Electrode spot positions uniformly enlarged to 2000 μm diameter, used as a spatial proximity mask | `SpotsResizeDiameter.m` |
| Labeled Surfaces (NoSmoothing) | Surface folder | Individual surfaces (Label_3 to Label_7) representing electrode-specific regions of interest, created without smoothing | `CreateSurfacesFromLabeledMap.m` |
| Labeled Surfaces (Smoothing X.XXXX) | Surface folder | Same electrode-specific regions created with Gaussian smoothing applied. The smoothing factor is calculated automatically as 2× the mean XY voxel spacing of the dataset; the value shown will differ from this example when applied to datasets with different voxel sizes. | `CreateSurfacesFromLabeledMap.m` |

> **Note on label numbers:** Labels 3–7 correspond to electrodes E03–E07. E01 and E02 are located outside the cochlear tissue in this specimen and are therefore absent from the masked Voronoi channel.
